## Agent's own summary

Migrated the library from Fleet Telemetry v1 to v2. parse_frame now reads unit quaternions (qx/qy/qz/qw), validates the required 6x6 covariance and 0..1 health, and targets api_version v2 with /v2 paths. Pose stores the quaternion as primary with roll/pitch/yaw kept as derived values (and still accepted by the constructor), scalar noise is derived as sqrt(trace(P_pos)/3) so isotropic fusion weights and noisy alerts are unchanged, and rotation/heading use sign-invariant quaternion formulas with defensive normalisation. Added a health alert (MIN_HEALTH=0.5, overridable), which adds one alert for amr-03, plus dedicated tests for health and quaternion-negation invariance. Fixture replaced with the openapi v2 fleet example as tests/fixtures/fleet_v2.json. One honest test adaptation: the exact yaw assert became pytest.approx(87.0) since 6-decimal wire quaternions quantise the angle by ~7e-5 deg. All 23 tests pass.
