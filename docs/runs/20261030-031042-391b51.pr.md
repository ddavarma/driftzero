## Agent's own summary

Migrated the library from Fleet Telemetry API v1 to v2: endpoints and api_version moved to /v2, orientation is now a Hamilton unit quaternion with sign-invariant rotation matrix, atan2 heading and direct-from-matrix tilt (quaternion normalized defensively), and scalar noise replaced by a validated 6x6 covariance with sigma = sqrt(trace(P_pos)/3), keeping Euler angles and noise as derived compat attributes so existing test bodies pass. Fusion now weights by the inverse position-covariance block (identical results on isotropic fixtures) and alerts gained a health kind with MIN_HEALTH = 0.5. Fixture converted to the exact openapi_v2 fleet example as tests/fixtures/fleet_v2.json (old v1 fixture removed), conftest repointed, endpoint literals updated, health expectations added to alert tests, and new tests added for health alerts, covariance validation, and q/-q rotation equivalence.
