## Summary

Migrated the fleet telemetry library from API v1 to v2. client.py now parses quaternion orientation, 6x6 covariance (shape/finiteness validated) and required health (0..1 validated), derives compat roll/pitch/yaw (rounded to 1e-3 deg, recovering exact v1 values) and scalar noise as sqrt(trace(P_pos)/3), and uses /v2 paths with api_version v2. orientation.py builds rotations directly from the normalized quaternion with the spec atan2 heading formula, so q and -q are identical; fusion weights are unchanged via the derived noise and fuse_heading uses the sign-invariant heading. alerts.py adds MIN_HEALTH=0.5 with a health alert kind (only amr-03 gains one). Tests: conftest points at the new fleet_v2.json fixture (byte-equal to the openapi_v2.json fleet example), endpoint literals updated to /v2, alert expectations extended only with the new health alerts, and a new test_v2.py covers health boundary/override, quaternion-negation invariance, covariance validation and sigma derivation.
